# Pathcraft

**An interactive, composable path-planning workbench.**  
用可组合卡片拼装路径规划算法，实时查看搜索过程、执行轨迹、最终路径与指标。

## 这是什么

Pathcraft 是一个运行在浏览器里的路径规划实验台：**2D 栅格**、**2D/3D 连续场**、**3D 体素**四种空间，共用同一套可组合卡片、同一套搜索回放与指标。

它把路径规划拆成可组合的参数模块：

- **搜索**：18 种策略，三个族 ——
  **搜格子**：A*、Dijkstra、贪心、BFS、DFS、加权 A*、JPS、IDA*、双向 A*、Beam、D* Lite；
  **撒点**：RRT、RRT*、PRM、可见性图；**优化曲线**：EGO-Planner；以及蚁群 ACO、遗传算法
- **代价**：间隙、转角、长度、斜向偏好、目标容差
- **约束**：安全膨胀、最大转角、禁止掉头、切角、扩展预算
- **算法内部参数**：采样步长、目标偏置、重连半径、PRM 连边半径、蚁群信息素挥发与启发指数、遗传算法变异率；
  EGO 的安全间距 s_f、平滑权重 λ_s、最大速度 v_max —— 只出现在真正用得上它的算法上，而且每一个都真的改变求解结果（有回归脚本逐个验证）
- **后处理**：可见性拉直、Chaikin 平滑（轮数）、路径抽稀（容差）

在左侧组件库选择模块，右侧装配表调整数值，中间实时观察搜索波前、最终路径和上一版路径。流程页把当前回放帧映射到实际执行分支，并显示队列、扩展节点与卡片编译位点。选择 RRT / RRT* / PRM / 可见性图时，画布切换到连续 2D 空间，路径以光滑折线输出。

## 可以做什么

- 八个场景，分三组：栅格 2D（凹槽、窄门、杂物场）、体素 3D（停机棚、竖井、柱林）、连续场（圆厅、浮板）
- 地图规格编辑：24–72 列 × 18–56 行，最多 4032 格；保留已有墙体并安全重排起终点
- 2D 地图编辑：画墙 / 擦除 / 笔刷 1·3·5 / 清空 / 恢复预设
- 栅格模式：A* / Dijkstra / 贪心 / BFS / DFS / 加权 A*
- 连续模式：RRT / RRT* / PRM / 可见性图，输出光滑连续路径
- 三维：正交投影视图（拖动旋转 / 滚轮缩放 / 复位），体素只画暴露面，路径按高度着色，柱子会真的挡住它后面的路
- 三维手感：转视角是"目标值 + 缓动"而不是一帧一跟，甩动有惯性，俯仰到限位会回弹；滚轮朝光标缩放，指着的格子留在原地
- 三维端点：拖动时实时重规划，并锁定当前层（按住 Alt 跨层移动）；标记永远画在真正会落下的格子上（手指位置只留一条虚线），落点非法或不可达时标记直接变警示色
- 起终点点击与拖动；靠近障碍时沿安全边界滑动，并按格吸附到最近合法格
- 搜索回放：播放、暂停、时间轴、0.5x / 1x / 2x；播放时路径从起点沿轨迹生长到终点
- 搜索 / 路径 / 旧路径图层开关
- 画布 80%–105% 缩放；滚轮或 `− / +`
- 「专注」收起两侧面板，地图最大化
- 左 / 右 / 下三个面板可拖拽缩放，缩到阈值自动收起
- 装配行拖动排序、拖出取消、拖动期间禁止选中文字
- 组件库按搜索 / 代价 / 约束 / 后处理分组折叠，并显示参数符号
- 流程页：可拖动的装配链 + 实时执行轨迹（当前节点、g/h/f、开放集、实际分支）；回放时按执行顺序逐行点亮伪代码，暂停就停在当前行
- 悬停卡片时，流程中对应代码行与画布上的影响区域同步高亮
- 参数详情页扫描并显示可行区间；不连续可行域不会被误锁死
- 指标页：环形代价图 + 分段条 + 图例
- 无解时在底部指标条显示原因，并直接打开对应参数
- 分享 URL、导出 JSON / CSV
- 单文件离线版本
- 中文 / English 切换
- 深浅两套主题：顶栏一键切换，首次打开跟随系统偏好；画布与 3D 台面一起换色，不是把亮色反过来

### 执行轨迹

流程页不是静态示意图：它按当前回放帧高亮实际执行分支，右侧给出当前节点、g / h / f、开放集和扩展状态；下方的装配表可以拖动重排，悬停任意一行时画布会高亮该参数影响的区域。

### 连续空间

切换到 RRT / RRT* / PRM / 可见性图后，搜索点变成连续采样点，最终路径经过碰撞检查与捷径平滑。地图规格、安全膨胀和起终点仍然生效。

![Pathcraft continuous planning](https://Kind0419.github.io/Pathcraft/preview-continuous.png?v=2)

### 三维

体素与连续场共用同一个正交投影视图：没有 WebGL，也没有 three.js，只有排序后的四边形和折线，所以单文件离线版仍然是单文件。

- **体素 3D**：只画暴露面，并把同一行的暴露面合并成一条矩形——30 × 21 的地板因此只有二十来个四边形，而不是六百多个。这不只是省性能：逐格绘制时，补缝用的描边会在整块地面上显出一层细网格，看着像瓷砖
- **一套材质，四档明度**：顶面、两个朝向的侧面、地面各一档，全部由同一个材质色派生。四种颜色硬编码会让体块变成"带图例的示意图"；同一材质分档才有"一个东西被一盏灯照着"的感觉。顶面还会随高度略微提亮，两层楼板因此不靠位置也能分开
- **接触阴影**：每个占据列、每个悬空球体/板在地面上投一块柔影。没有影子，柱子和球就像贴纸
- **连续场**：障碍是解析图元（球 / 方盒 / 胶囊 / 圆盘），按当前分辨率临时栅格化出一张 3D 栅格；分辨率是运行时参数，距离场随时可按新分辨率重建
- **高度着色**：路径从低处（浅苔绿）渐变到高处（琥珀色）。正交投影没有透视，不靠颜色就分不清"爬升"和"平移"。路线上方还有一层地面投影，爬升时影子与线分离，高度差直接可见
- **遮挡关系**：路径与墙体进同一个深度表排序，柱子会真的挡住后面的路段；同时保留一层极淡的透视重影，避免路线在目标前"凭空断开"
- **端点操作**：直接拖动 S / G 就能移动端点（和 2D 一样），也可以先点工具栏的「起点 / 终点」再点场景。拾取沿视线步进，所以能落在上层楼板上，而不只是地面那一层；松手后吸附到最近的合法格
- **手感**：拖动带惯性，松手后会顺着方向滑一小段再停；滚轮缩放是连续缓动的，不是一格一跳；双击复位视角会走最短路径转回去（转过好几圈之后也不会倒着转两圈）
- **帧循环**：相机状态放在 ref 里，由 requestAnimationFrame 驱动重绘，拖动时一次 React 渲染都不发生——这是"跟手"的前提
- **采样规划**：RRT / RRT* 在三维里同样可用——树长在连续坐标里，栅格只当作碰撞检测的预言机
- **轨迹优化**：EGO-Planner 同样在三维里可用，而且它本来就是为三维写的。它不搜格子，
  而是把一条三次 B 样条按三个代价拉出来：平滑（控制点差分的平方）、碰撞（对撞进障碍的
  控制点建 `{p, v}` 锚点，代价是分段三次函数）、可行（不改形状，只把 Δt 拉长）。
  碰撞项只问真的卡住的那几个点，不建距离场——这是它和 ESDF 那一套的全部区别

## 算法范围

三维空间里可用：A*、Dijkstra、贪心、BFS、DFS、加权 A*（在 26 邻域栅格上），以及 RRT、RRT*（连续树 + 栅格碰撞检测）。JPS、IDA*、D* Lite、双向 A*、Beam、元启发式只有 2D 实现，在三维场景中直接标注「不适用」而不是偷偷换成 A*。

### 栅格图搜索

| 策略 | 优先级 |
|---|---|
| A* | `g + h` |
| 加权 A* | `g + 1.5h` |
| Dijkstra | `g` |
| 贪心最佳优先 | `h` |
| BFS | FIFO 入队顺序 |
| DFS | LIFO 出栈顺序 |

### 改进与增量图搜索

| 策略 | 做法 | 说明 |
|---|---|---|
| JPS | 跳点 + 强制邻居剪枝 | 剪枝规则要求等步长代价，因此间隙/转角权重不参与 |
| IDA* | 逐轮加深 + 置换表 + 贪心上界 | 内存近似常数，可能略次优 |
| 双向 A* | 两端交替扩展，在最优相遇点拼接 | 按格搜索，没有“进入方向”，转角权重不适用 |
| Beam | 每层只保留 w 个候选 | 宽度由「候选宽度」卡控制，快但非最优 |
| D* Lite | 从终点反向维护 rhs/g | 起终点变动时复用距离场，可关「增量复用」强制重算 |

### 连续 2D 空间

| 策略 | 做法 |
|---|---|
| RRT | 随机采样 + 最近邻 + 步进 + 碰撞检查 |
| RRT* | RRT + 邻域重连，路径更短 |
| PRM | 采样路线图 + k 近邻连接 + Dijkstra |
| 可见性图 | 自由空间路线图 + 8 邻域 + 可见捷径 + Dijkstra |

连续模式默认对输出做一次视线捷径，并在安全间隙允许时对转角做圆角；再按“可见性拉直 / Chaikin / 抽稀”卡处理。安全膨胀会同时用于采样点、边碰撞和圆角检查。

### 元启发式

| 策略 | 做法 |
|---|---|
| 蚁群 ACO | 信息素 τ^α·η^β 构造路径，逐轮蒸发与沉积；画布显示信息素热度 |
| 遗传算法 | 以 RRT 路径播种，6 个路径点作为基因，选择 + 交叉 + 扰动，精英保留 |

两者都用「迭代轮数」卡控制轮次（建议 20 轮以上），结果随轮次改进，不保证最优。

### 不适用是明说的

某些参数在特定算法上确实无效（例如 JPS 的间隙权重、双向 A* 的转角权重）。这些卡片不会假装生效：装配表里标“不适用”，卡片保留在装配表中但不参与编译，指标面板与执行流程会给出对应说明。

## 快速开始

### 在线

<https://Kind0419.github.io/Pathcraft/>

### 本地

需要 Node.js >= 22.12 和 pnpm。

```bash
git clone https://github.com/Kind0419/Pathcraft.git
cd Pathcraft
pnpm install
pnpm dev
```

打开 `http://127.0.0.1:5173/`。

### 检查、构建、单文件

```bash
pnpm typecheck
pnpm build
pnpm bundle
```

- `pnpm build`：类型检查 + Vite 构建，产物在 `dist/`
- `pnpm bundle`：生成 `release/Pathcraft.html`
- 单文件版本双击即可离线打开

## 项目结构

```text
src/
  App.tsx                 布局、状态、URL、拖拽、地图规格、参数检查、导出
  styles.css              全部样式（单一设计系统）
  components/
    CanvasView.tsx        Canvas2D 绘制、命中、起终点、缩放、画笔、连续路径
    Card.tsx              装配行、滑块、开关、choice chips
    FlowPanel.tsx         图搜索 / 连续采样执行轨迹、卡片编译位点、流程拖拽
    Icon.tsx              线性图标
  lib/
    types.ts              公共类型
    cards.ts              26 张卡、参数符号、编译位点、默认值
    maps.ts               预设地图、规格限制、clearance
    planner.ts            图搜索、策略优先级、代价、约束、调度
    continuous.ts         RRT / RRT* / PRM / 可见性图、连续碰撞、平滑
    feasibility.ts        参数可行区间扫描
    i18n.tsx              中英双语文本与语言上下文
    heap.ts               MinHeap
scripts/
  check.ts                planner 冒烟检查
  package.mjs             单文件打包
```
